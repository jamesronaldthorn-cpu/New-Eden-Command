# New Eden Command v3.5.0

## Hunting / Roam Command Update

This release expands Hunting into a complete target-analysis and roam-planning workspace.

### New
- Activity trend history: HEATING / STEADY / COOLING.
- Target system dossier with ranking reasons.
- Stargate topology labels: Dead-end / Pipe / Junction / Hub.
- Nearest low-sec / high-sec escape analysis.
- Automatic scored roam-route builder with backtracking penalties.
- Copy roam route or send it to EVE as autopilot waypoints.
- Expiring manual hunting intel.
- Persistent local visit/outcome history.
- Optional zKillboard system-history lookup with one-hour local cache.
- Historical ratter/mining/gang/PvP classification from public killmail context.
- Interactive hunting map using SDE coordinates and stargate links.
- New Blops Hunt profile with jump-envelope/fuel context and staging suggestions.
- PLAN BLOPS action into the existing Jump Calculator.

### Improved
- ESS Hunt gains trend, topology, manual-intel and historical killmail context.
- Hunting graph data is cached in memory for faster repeated scans.
- GitHub update feed defaults to the public New Eden Command release feed.

### Data limitations
- Public CCP activity is not live local.
- Exact pilots-in-space are not inferred.
- Live ESS balances are not invented.
- zKillboard is historical third-party public data and is labelled as such.
